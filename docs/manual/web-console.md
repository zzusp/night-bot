# Web 控制台使用说明

Night Bot Web 是可选界面。管理员启用后，通过本机地址登录；令牌由管理员从受保护的安装目录提供。

## 与 Bot 对话

在「与 Bot 对话」输入问题或任务，Enter 发送，Shift + Enter 换行。中文输入法确认候选不会发送。侧栏可回到最近对话，刷新后会从服务端恢复记录。

「已接纳」只表示 Bot 收到了消息，后续回复和任务状态还会继续更新。仍在确认接纳或网络故障时保留草稿，先点「核对发送状态」，不要重复发送。只有明确接纳才清空草稿；未接纳时恢复编辑，结果仍未知时不自动重放原消息。

草稿只在当前标签页内存中保存，不写浏览器持久存储；切换页面或重新登录可继续，刷新、关闭页面或主动退出会丢失尚未发送的草稿。关闭页面不取消 Bot 已接纳的工作。

## 查看任务

「任务」按执行中、排队中、等待中和已结束筛选。「等待中」可能是等待输入或依赖，详情说明实际原因。「已结束」也可能包含取消，请查看具体状态。

列表每页 20 条，搜索只筛选当前页。详情展示目标、状态、时间线、处理结果、阻断和交付记录；同一任务只有一个执行会话。

「执行记录」显示 Pi 当前已提交的执行上下文，包括正文、工具名称及结果。压缩或分支后不保证包含原始全部历史；系统指令、思考和工具参数不展示，路径及典型凭据会脱敏。正在提交或暂不可读时会明确提示，不用空记录代表成功。

## 查看渠道

「渠道」显示配置中的启用状态与适配器接入状态。已启用不等于厂商在线或真实发送已验收。点击渠道卡片筛选会话，再点会话可按聊天方式查看原消息和 Bot 回复。

渠道消息是只读视图。通知待核实或失败会保留原状态，不标成已送达。页面不会替你向这些渠道发消息。

## 连接与外观

右上角可刷新概览和切换浅色/深色，手机使用左上角导航。连接中断时可继续读上次数据，页面会标明；恢复后重新获取。令牌失效后重新登录，退出会清除当前登录会话。
