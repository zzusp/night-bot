# Web 控制台使用说明

Night Bot Web 是可选界面。管理员启用后，通过本机地址登录；令牌由管理员从受保护的安装目录提供。访问令牌与浏览器会话是不同凭据：浏览器会话有效期为 12 小时，服务重启后须重新连接，仍可使用原访问令牌；这不表示令牌本身失效。网络、服务或局部权限错误不会直接退出，页面先只读核对会话，无法核对时保留内容并提示恢复连接。

本页面向操作者；界面开发与维护统一遵循仓库根目录的 [DESIGN.md](../../DESIGN.md)，本页不另立 UI/UE 规则。

## 与 Bot 对话

在「与 Bot 对话」输入问题或任务，Enter 发送，Shift + Enter 换行。中文输入法确认候选不会发送。侧栏可回到最近对话，刷新后会从服务端恢复记录。

Web 只有一个固定对话，不提供新建入口。旧版本的对话和执行记录保留，仍可打开并输入；新消息统一接续当前 Web 对话，接纳后跳转。历史消息、任务关联与未决收据不会被删除或合并。外部渠道继续各自独立。

「已接纳」只表示 Bot 收到了消息，后续回复和任务状态还会继续更新。仍在确认接纳或网络故障时保留草稿，先点「核对发送状态」，不要重复发送。只有明确接纳才清空草稿；未接纳时恢复编辑，结果仍未知时不自动重放原消息。

草稿只在当前标签页内存中保存，不写浏览器持久存储；切换页面或重新登录可继续，刷新、关闭页面或主动退出会丢失尚未发送的草稿。关闭页面不取消 Bot 已接纳的工作。

发送期间可切换到其他对话；原请求的回执仍归原对话，不会跳走当前页面。切页或登录过期后，未决消息的核对入口会保留；只有明确不存在原请求时才允许使用同一请求重试。输入的缩进和换行会原样发送。

Web 与所有外部/自定义渠道会话共用同一布局，顶部均可切换「对话」与「执行过程」，会话名在工作区顶栏显示，宽屏提供工作动态侧栏。只有 Web 显示输入框。「对话」展示消息接纳及实际回复；「执行过程」分别展示 Router 安排与本会话关联任务。Router 组读取当前 Router 的正式 Pi 历史；任务组默认折叠，点开后在同一 Chat 页读取该任务正式执行上下文，包括工具输入、输出和来源，收起即停止读取。任务关联由 Host 持久保存，包含已完成和已归档任务，不随 Router 换代清空；关联查询暂不可用会明确提示，不显示成「暂无关联任务」。刷新和网络恢复后从服务端重新读取，不在浏览器另存一份历史；任务组刷新后须重新展开。当前 Router 的换代、压缩或分支可能使更早 Router 记录不在本页，各组会说明上下文范围。

## 权限与审批

右上角「权限与审批」由已登录的安装操作者使用；普通任务、模型回复和渠道成员不能切换安装权限。当前模式、可选档位、保护状态和审批记录均来自 Host，不在浏览器保存另一份权限配置。 退出、认证失效或认证会话更换会清除权限面板中的审批详情和未提交模式草稿，旧请求的迟到响应不会恢复这些内容；聊天草稿仍按原对话恢复规则处理。

| 档位 | 行为 |
|---|---|
| 请求批准（`ask`，默认） | 可扩大范围的文件或命令动作需要单次批准；未获批准或已拒绝时不执行该动作。 |
| 帮我批准（`auto`） | 仅审查需要批准的动作，使用当前配置的通用模型经 Pi 作无工具决定；只有明确批准才放行，无法确定或模型失败转交人工。 |
| 完全访问（`full`） | 必须由操作者明确选择并保存；可越出业务工作目录，按当前操作系统账号权限执行，不取得管理员权限。进程不再隔离，同账号可访问的凭据和 Host 私有文件不受进程隔离保护。 |

选择档位后点击「保存权限模式」；完全访问的按钮明确为「保存为完全访问」，不因展开面板或选择单选项而生效。Web 保存经 Host 写入私有配置并切换当前运行态，结果重新向 Host 读取。切换模式会使旧待批请求和未消费授权失效，不把原审批套用到另一模式或参数。

保护提示直接展示 Host 报告的后端与说明，区分「隔离尚未核实」「隔离不可用」和「进程未隔离」。请求批准与帮我批准仍要求实际受控后端；后端不可用时拒绝执行，不静默退为完全访问。模式已保存不证明 Windows 或其它平台的隔离已经可用，也不表示某次工具调用已成功。

审批条目显示 Host 筛选、脱敏后的业务摘要、目标、工作目录、命令摘要、参数摘要和调用来源；批准所需的准确业务路径会保留供核对，凭据与秘密仍隐藏，不展开原始参数、环境变量或私密审计。核对后选择「仅批准此次」或「拒绝此次」；批准绑定该 actor、调用、参数和范围，不成为其它动作的权限。结果区分等待批准、已批准此次、已拒绝与已撤销；批准不等于执行成功，执行结果仍查看任务记录。Host 确认授权仍属于当前有效调用且尚未消费时，才显示「撤销未执行授权」；撤销会收回该授权，不回滚已经发生的效果。已消费、过期或已经结束的项不提供可执行撤销入口，提交冲突后只核对状态，不重试原决定。

提交时禁止重复点击；关闭面板不会取消已经提交的操作。失败后只重新获取当前状态，不自动重发决定；请求过期或已结束返回冲突时，不再重试批准该请求。刷新、重连和重新打开面板均只读恢复。冷恢复保留已保存模式，将原待批请求撤销，不重建等待、不自动执行原动作。

## 查看任务

「任务」按执行中、排队中、等待中和已结束筛选。「等待中」可能是等待输入或依赖，详情说明实际原因。「已结束」也可能包含取消，请查看具体状态。

列表每页 20 条，搜索只筛选当前页。详情展示目标、状态、时间线、处理结果、阻断和交付记录；同一任务只有一个执行会话。

「执行记录」显示 Pi 当前已提交的执行上下文。Web 面向持有安装令牌并登录的单操作者，提供本安装的任务检视，不是向渠道群成员发布。Host 对工具输入与结构化结果按固定工具、字段和类型选择可展示内容，再做秘密脱敏；未知工具标为「未公开工具」，未知输入和结果字段不显示。点开条目可查看获准的输入、输出和来源；结果须与同一会话的准确调用及工具名配对，同次调用合为一项。孤立或冲突结果保留事件与状态，不猜测正文；只有调用记录而没有结果时显示「等待结果」，不表示工具正在执行。

在任务绑定的严格已提交历史中，`read/read_window/grep` 与 `web_search/web_fetch` 经准确调用及工具名配对后，可展示该任务已声明的业务文字；安装私有业务文件不等于该操作者无权查看。JSON 业务文件仍按文字处理，不当作工具结果字段对象裁剪；无需脱敏时保留原有空白，长文沿同一版本分页。凭据与私密路径继续隐藏，网页搜索和读取结果中的 URL 也隐藏。任务检视权限不扩大记忆与学习技能的独立读取范围；命令、作业、memory/skill 的历史工具正文不泛透传，记忆和技能全文继续使用下述「复盘与学习」的显式授权读取入口。正式任务及 Router 的获准业务结果仍可显示。

每页最多 50 条正式历史，可查看更早记录或回到最新。长正文用「上一段」「下一段」按同一版本继续读取，每段最多 16000 个 UTF-16 单位，复制按钮只复制当前段；记录已变化时重新获取，不把不同版本正文拼成全文。来源包含服务端公开的会话、历史条目和调用标识，不包含宿主私密路径。

压缩或分支后不保证包含原始全部历史；系统指令、隐藏推理、凭据、原始参数对象和私密审计不展示。正在提交、尚未开始或暂不可读时会分别提示，不用空记录代表成功。

任务结果、执行动态和阻断只显示现有业务记录的必要字段，不包含内部参数与凭据。任务尚未开始、记录正在提交和读取失败是不同状态；未知来源的输入标为「用户」或「渠道成员」，不会归到当前操作者名下。

「复盘与学习」展示本任务实际记录的复盘及记忆、技能变更，保留来源任务、复盘、业务事件、作用域和版本。「复盘完成」不代表已经学到或应用；「候选，未应用」「未应用」与「已应用」分别标明。Host 尚未提供可核验记录时会显示暂不可读，不显示成没有变更。

列表不包含私有正文。只有当前身份获权时，才能点击「读取授权正文」按该版本读取；无权时按钮禁用。正文权限拒绝后不继续显示缓存内容，版本变化须刷新后重新打开。关闭正文或切页停止这次读取，不修改记忆、技能或任务。任务的执行记录、复盘视图入口随地址保存，刷新后仍从 Host 重读。

## 查看自进化

从侧栏打开「自进化」，查看当前身份有权读取的记忆与复盘形成的学习技能。上方显示已应用、候选及已采集的使用次数；下方按最近更新排序，每页 20 条，可按记忆/学习技能筛选和手动刷新。

记忆读取/搜索和学习技能正文加载从本功能启用后开始记录，之前的调用不会补算；「未记录」不表示从未使用。资源加载次数包含运行时自动准备，不证明模型已调用、采纳或执行技能，外部安装技能不在此统计内。列表只显示当前保留条目的安全元数据，不是完整变更历史；遗忘或过期内容不再列出。需要核对任务内的学习来源或获授权正文时，进入该任务的「复盘与学习」。

## 查看渠道

「渠道」分别显示配置启用、Host 报告的适配器阶段及健康检查。阶段区分启动中、等待认证、就绪、暂停、恢复中、监听中、失败和已停止；没有阶段数据时显示「待核实」，健康布尔值缺失时显示「健康状态未报告」，不由「已启用」推断已连接。等待认证或适配器异常仅给中性提示，不展示登录信息、凭据或底层错误正文。已就绪不等于已监听，已启用也不等于厂商在线或真实发送已验收。点击渠道卡片筛选会话，再点会话可按聊天方式查看原消息和 Bot 回复。

渠道会话同时出现在左侧「最近对话」中，标题显示会话名称，消息显示发送人姓名；名称缺失时使用中性标签，不用群聊或用户 ID 充当名称。渠道输入框暂时隐藏，页面不会向这些渠道发消息。通知待核实或失败会保留原状态，不标成已送达。钉钉卡片的「外发已授权/外发未授权」仅表示已保存的配置授权，未报告则明确标注，不表示当前可以发送。

### 添加渠道

已登录的安装操作者在渠道页点击「添加渠道」，选择「钉钉」后填写本安装唯一的渠道标识，选择「群聊」或「私聊」。页面直接使用 Bot 运行环境当前登录账号，无需填写 profile 或选择账号；未登录、没有当前账号或当前账号有歧义时拒绝保存，请先在 Bot 运行环境完成钉钉登录并确认唯一当前账号。选择「按 ID」或「按名称」，填写一个群或用户目标；可另填显示名称与渠道职责。切换会话类型或填写方式会清空旧目标，避免误用；名称必须能唯一匹配，不会自动选择同名目标中的第一个。不要输入令牌、密钥或带凭据的链接，此处不管理钉钉登录。

点击「保存钉钉渠道」只新增配置，不覆盖已有渠道。收到明确成功后，页面显示已保存待重启、当前尚未连接及实际保存的外发授权状态；正常重启 Bot 后才沿既有可选插件接入。保存本身不验证厂商认证、目标解析、订阅或消息发送，已有钉钉配置通过卡片的「编辑配置」单独修改；页面不提供删除、启停或代发按钮。

保存期间不能重复提交。重复标识会提示未覆盖已有配置，字段校验失败或保存不可用时保留草稿，可以修正后主动保存。网络或服务端异常导致结果未知时，页面按原渠道标识只读核对，并保留「核对保存状态」；不会重发 POST 或自动更换标识。发现同标识只能确认该标识已有配置，安全摘要不包含账号/目标，不能确认本次目标已保存；暂未发现或核对失败仍不能重复保存。

关闭对话框后，同一渠道页内可重新打开继续填写或核对。新增与编辑草稿及反馈只属于当前认证会话；退出、登录失效或认证换代会清除，旧响应不会恢复到新会话。它们不遵循聊天草稿的跨页恢复规则；刷新或离开渠道页前先核对未决保存状态。

### 编辑已保存的钉钉渠道

点击指定卡片的「编辑配置」，从服务端读取已保存字段。渠道标识不可改，账号沿用原保存账号；可编辑显示名称、渠道职责、群聊/私聊、按 ID/名称的目标和外发授权。显示名称留空会移除原名称，职责保留原换行；切换会话类型或填写方式会清空旧目标。卡片筛选与编辑是独立按钮，编辑不会切换当前会话筛选。

点击「保存渠道修改」提交完整草稿与读取时版本。配置已被其它操作修改时，旧版本保存会明确拒绝，保留原草稿；点击「重新加载最新配置」才用最新配置替换草稿，再重新编辑。不会自动覆盖新版本。旧目标有未决任务、输入或投递依赖时不能切换真实目标，须先处理旧依赖；重复重启不会解除该阻断。

修改名称、职责或同一实际目标保留原绑定、水位和外发配置；真实目标切换由 Host 隔离新旧身份，新目标外发关闭，旧任务、会话和通知不会迁往新目标。职责可能参与后续任务推理，不承诺只影响新建任务。新增与编辑均有「外发授权」选项，新增默认「关闭：仅接收消息」；明确选择「开启：允许回复和通知」后保存，正常重启才允许向该会话发送正常回复、通知和附件，包括此前已排队未发送的通知。关闭授权同样需重启，不撤回已发送消息。修改目标时授权自动关闭且暂不可开启，请先保存目标，再重新编辑授权。页面不提供热加载。

「配置未变化」也是有效回执，是否待重启由保存和运行状态决定。卡片分别显示保存配置、当前运行配置和健康状态；旧配置仍运行时不会标成新配置已应用。保存/加载版本一致仍可能尚未激活，冷启被旧依赖阻止时会明确提示。已激活也不替代连接、监听或真实发送验收。

断网或回执不完整时保留原字段和版本，只能点击「核对保存状态」，不会重发 PATCH。只读核对版本已变化且全部字段一致时，仅确认当前保存配置与草稿一致；版本未变或字段不同仍保持未知与锁定，不认定原保存没有发生。确认当前配置后可点「重新读取并编辑」开始下一次明确编辑。关闭或认证换代的草稿边界与新增表单相同。

## 连接与外观

右上角可刷新概览和切换浅色/深色，手机使用左上角导航。连接中断时可继续读上次数据，页面会标明；网络恢复后会只读重新获取；也可手动刷新。令牌失效后重新登录，退出会清除当前登录会话。

另一标签页重新登录后，旧标签页可能提示连接状态变化。页面会只读同步当前会话并保留草稿，请确认后手动重试；不会自动重发刚才的操作。退出处理中会等待服务端回执，结束后才能重新登录。概览中单一区块读取失败时，其余信息仍可查看；失败不会显示成「暂无任务」或「尚未配置」。

安装、升级和禁用见 [本机运维说明](../ops/web-console-local.md)；代码与验收入口见 [本轮目标](../acceptance/web-console/goal.md)。

## 设置助手、模型与凭据

从侧栏进入「设置」。助手显示名称及内置图标保存后用于登录页、Logo、消息和输入提示；支持月亮、星光、机器人、叶片，默认 Night Bot/月亮。不读取图标文件或外部图片，不修改项目/渠道/会话 ID，也不修改模型角色。

模型 API 表单支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。输入 HTTPS 地址（本机可用 HTTP）及模型名，确认后创建独立 `web-model` 默认路由；其它已有路由保留，正常重启才生效。该路由使用 `NIGHT_WEB_MODEL_API_KEY`。请先保存模型配置，再在当前模型的 API Key 区替换密钥。保存不发验证请求，也不证明模型可用；复杂模型能力、上下文或推理设置仍按 Pi 配置说明维护。

同一个 API 要配置多个模型时，使用下方「模型列表」：选择已有路由，点击「添加模型」，填写服务商实际支持的模型 ID 和可选显示名称。新模型复用该路由的 API 地址与凭据，不必再创建 `web-model` 或重复填写 Key。可按 ID/名称筛选、逐项编辑或删除。编辑只改 ID/显示名称，保留其它能力参数；显示名不是 API 请求中的模型 ID，填入新名称不能证明服务商已开通该模型。

保存后，一级分诊、Router、任务执行的模型选项会更新，可分别保存实际选择；配置需正常重启后生效，不中断当前运行。默认模型、角色、环境变量或有效任务默认配置正在引用的模型不能改 ID 或删除，先切换对应配置再操作；显示名称仍可编辑。不能删除路由中最后一个模型。环境变量继续优先于保存的角色配置，网页不会改环境变量。

对于启用 resident 的安装，删除或改 ID 前还需在「任务执行」中保存一次明确的模型选择，避免旧任务默认配置重新引用已移除模型；有效任务环境覆盖也满足此条件。新增和修改显示名称不受这一步限制。

删除前确认准确模型；新增/编辑/删除都做版本核验。保存结果不确定或发生并发冲突时，草稿保留且不自动重复写入，点击「重新读取模型列表并替换草稿」核对当前保存值。列表更新只证明配置已保存，不证明外部模型请求成功。

API Key 和 GitHub Token 只显示是否配置及来源，已保存值不返回浏览器。替换或清除必须确认；输入默认掩码，可手动显示，提交后清空，不存浏览器。凭据沿既有存储进入安装目录 `data/secrets/credentials.json`（既有 version-one 格式），普通配置只保留引用。环境提供的凭据只读；清除仅处理保存值，不能删除启动环境里的值，若仍有外部来源会继续显示其状态。当前模型无显式引用时沿 Pi 的 provider credential namespace 管理，不代表检测了所有其它 Pi 登录来源。不要把真实密钥写进 API URL、渠道字段、日志或仓库。

GitHub Token 只在已经获准的**完全访问 Shell**最终启动时注入；ask/auto 不自动注入。保存凭据不授予推送、合并、发送或其它副作用权限，不修改全局 process.env。模型引用密钥的后续读取与 GitHub full Shell 使用已保存的新值；当前模型路由的修改仍须重启。网页不自动验证或联系 GitHub/模型服务。

重新读取会清除本页未保存输入；发生版本冲突先重新读取。保存响应丢失时不会自动重试，先重新读取状态再决定是否显式替换。密钥状态只能证明有保存值，不能证明某个具体值已被接纳或网络可用。

## 配置自定义渠道

渠道页的「添加渠道」可直接选择已安装的自定义插件并填写其表单；「设置」页不再显示自定义渠道区块。已有渠道配置不受影响，实例修改按插件运维说明处理；渠道页现有管理操作与服务端接口保留。未提供网页表单的插件会明确提示按其说明配置。新增不会覆盖同标识的已有渠道。管理员先按 [插件协议](../CHANNEL-PLUGINS.md)安装可信渠道插件；网页只发现清单，不上传或执行代码。声明网页表单的插件可以从渠道页新增并显式启用，默认停用，保存后正常重启生效。凭据字段只填环境或安全存储的引用名称，不填明文。插件未声明表单会明确显示，不猜测或套用钉钉字段。运行中实例须先按插件运维流程停用、正常重启，再修改；本页不提供在线停用、目标迁移、删除或热加载。钉钉继续使用原独立配置表单及其外发授权、切换目标撤权规则。
