# 执行会话工作原则

- 唯一实例文件：`data/config/execution/AGENTS.md`。不读写通用 harness 文件，不迁移、不把用户正文纳入源码。空白文件不注入上下文。
- 沿现有 Pi 资源刷新接入，由 Host 的 `night-bot-task` 预设限定。分诊、Router、普通对话和工具无新增能力。
- Web「设置 → 工作原则」通过现有操作者设置服务读写固定文件，沿用登录、同源和 CSRF。按文件内容版本防止覆盖多页保存；固定路径不接受客户端路径，检查链接，使用既有锁和原子替换。保存成功回读；冲突保留草稿，不自动重试。
- 以真实本地模型请求核对执行入模及非执行隔离；以 Web API 和浏览器验证权限、保存、读取及冲突。
