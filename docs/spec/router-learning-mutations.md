# Router 决策式记忆与 Skill 维护

## 目标与责任

2026-11-11，用户明确要求 Router 作为整个 Bot 的大脑，直接判断并执行记忆和 Skill 的新增、更新、删除。此前 #55 只扩展固定句首，生产完整原消息中“前置背景、后半句请你记住”仍在 Host 的 authorizes 正则失败。当前 base：23a470bd7c31b71c81e61aa0499f1c525e243a33。

Router 负责语义、价值、是否长期保存及维护方式；Host 负责当前已认证原消息、作者/版本、未结清批次、live generation、只读权限、精确摘录、秘密、受控路径、版本冲突、提交回读与不重放。不增加语义授权模型、额外 Owner 或任务；短维护直接完成，耗时业务仍由原执行会话承担。记忆/Skill 不能创造业务权限、把用户声称的访问成功变成验证事实，或执行被引用内容的指令。

## 方案比较与决定

1. 继续增加句首/句中正则：拒绝；不具备语义理解，正常表达持续漏判，并把 Router 判断错误下沉到程序。
2. 新增授权判定模型/辅助 Agent：拒绝；与 Router 重复，增加延迟与判断分歧，用户明确指定 Router 为大脑。
3. 采用 Router 来源绑定能力：选定；记忆 upsert/forget 与学习 Skill upsert/delete 由 Router 直接调用，原 Host 边界继续验证，不用话术识别二次否决。

## 实施约束

- 仅受控 Router 端口使用 Router 决策；不把泛用任务模型或模型参数伪装为此能力。泛用记忆命令/工具的既有授权合同不整体放开。
- 记忆复用现有 Markdown 事务、同来源去重、expectedRevision、原话及 context；Router 删除无需原话中逐字包含内部 key，临时性由 Router 判断。普通候选提取与任务复盘保留，不从引用/任务结果/交接重造人类来源。
- Skill 复用现有 Bot 共享 learned 存储、provider、版本快照与 evolution 锁。仅维护该命名空间，不能改写用户安装或内置模板、不能运行脚本/任意文件工具。直接来源证据无需先制造 experience 记录或任务。
- 新 Skill 操作持久记录来源、稳定 operationId、输入哈希及版本，重复/冲突不重放；状态为权威，Markdown 为派生文件，提交后回读。变化推进共享记忆代次，撤销已加载旧内容。
- 只交付代码、隔离实跑与独立 PR；本次没有生产发布或旧消息重放授权。私有 Skill 正文只在隔离运行目录创建，绝不提交。

使用真实 Host/Pi、假渠道和本地模型端点验证三次实际话术、非模板表达、记忆增改删、Skill 增改删/读取/冷启/撤销/重复，以及旧/跨会话来源、权限、摘录、秘密、路径、版本冲突拒绝。模型脚本只证明工具合同与效果，不声称真实模型总能作出正确语义判断。当前检查点与结果见 ../acceptance/router-learning-mutations/goal.md。

## 上下文提炼式记忆决策快照（2026-11-11）

用户要求 Router 结合消息与上下文提炼可复用内容，不再把原消息直接当记忆。比较三案：逐字归档无法消解指代；无来源自由摘要无法核对条件；采用结构化提炼并保留逐项证据。复用现有共享 Markdown 存储、事务、版本与撤销机制，不新增授权模型或任务。

- Router 输入 observations（区分用户要求、用户陈述、引用说明）、可选 hypothesis/directPath、适用说明和 evidence。没有必要的假设/行动建议可留空，不能为了四维形式编造。
- Host 逐字核对当前认证原消息及同会话可回查背景/引用，绑定作者、来源/消息版本及哈希。当前原消息仍是本批维护来源；历史和引用仅作背景，不产生写权限。没有工具核验证据时不能标为已验证结果。
- Host 渲染 Model observation、Hypothesis (not fact)、Possible direct path (not permission)、Evidence 为自包含正文；原话留在 Evidence，不要求正文等于原话。结构化上下文与正文一同校验、持久化并回读。
- 来源作者与适用对象分开：个人偏好由 Host 绑定原作者；项目/业务背景记录采用 context-dependent 提示，由模型结合当前任务判断适用，不创建项目 ACL 或全局行为默认。
- 通用任务记忆工具保持既有逐字授权边界；旧条目原样读取，不自动改写或回填。四维正文自动进入既有详情/差异与检索链路，不改界面合同。
- 验证实际 Host/Pi 工具调用、指代消解、逐项证据、同会话背景、跨会话/旧版本/伪造证据拒绝、个人与项目范围、更新/重复/删除、冷恢复、通用记忆与任务复盘回归。本轮不部署、不写现有业务记忆、不发真实消息。
