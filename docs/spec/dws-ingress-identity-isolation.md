# 钉钉入站与未知外发隔离

同群通知的 `starting` / `unknown` 只影响可能是该通知回声的消息。只有同绑定、同命名空间的明确发送者身份可以排除候选；相同账号、通用自动化标记或不明命名空间均不能证明回声。回声仍须匹配精确消息 ID。原通知的送达核验、未知效果和禁止重发保持不变。

不采用扩展外发历史分页（读不到不是未发送证明），也不只按发送者过滤（补拉遇到第一条候选仍会停止）。插件在允许继续扫描之前，按候选 ID 耐久登记待核对项，保留直接引用已登记候选的依赖。完整历史页与单条核对进度独立；旧恢复下界先保守使用，之后用严格完成的范围水位做增量。使用既有补拉节奏独立精确重取待核对项，复用同一接纳、去重和关闭排空。精确读取无结果保留原记录，写入失败不能算接收成功。

用默认 Host 与 fake DWS 核实：无 ACK 的原外发不重发、同账号候选和已知引用保留、同群真人实时和历史来源推进至分诊终态、缺旧候选的冷恢复不停止新历史、明确回声和撤回仍不可误接纳。不改外部账号、不部署或修改线上数据。
