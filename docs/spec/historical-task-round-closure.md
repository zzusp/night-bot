# 旧任务正常轮结清

UAT 原账本有两个 `active` 项，Web 因而显示「未运行」。原业务 `task_result`、同版本决定、输入确认和排空都已落盘。旧版把业务 `blocked` 留作开放状态；新版按轮次结束结清，保留受阻结论。

复用 Host 恢复流程补记旧轮终态：严格回读原 Pi，SQLite 在同一事务比对当前状态、版本、决定、ACK 和排空，再追加维护收据并更新任务。只改 Web 会让筛选、详情、归档账本不一致；重用普通完成命令会生成一个新的 Router 事件。只处理同一轮已提交且已排空的普通任务，不清理过去的未知效果、唤醒或回执，不补发、不放行依赖。不能证明的记录保持原状。
