# Router 上下文分类与启动恢复

- 保留 Pi 原生当前占用与 Router 有效窗口。明细只从当前 Pi 投影按原生 system 段、工具声明及已知消息/工具结果类型估算。不解析提示正文、不读完整日志文件、不按比例凑数；不一致时保留原总量和未分类。
- 使用现有启动恢复和同会话串行队列。优先安排耐久待办事件，空闲活跃 Router 逐个重开现有 Pi 会话。同一个实例的定时巡检不重复预热；空闲加载不创建会话、不推进业务、不触发模型或外发。
- 不做页面访问触发恢复，也不替换丢失/损坏的原生会话。沿用作用域、严格 journal、代际、关停排空与无重放边界。用真实本地 Host/Pi 验证重启恢复及下一条新事件，浏览器验证分类和空态。
