# Web 执行历史资源复核批量读取

任务详情和 Router 共用执行记录：轮询即使没有新行，也要重新核对页面持有的记忆与 Skill 正文。UAT 原样本加载 5 条不同 learned Skill 时，空轮询 2.08–4.95 秒；同一位置没有资源正文时为 7–81 毫秒。逐条拿共享记忆锁会重复读取相同的索引和 Skill 状态。

先减少同一请求中的 I/O，不引入读写锁、跨请求缓存或新接口。记忆条目在一个现有锁窗口内共用当前根索引，只读通过身份、路径、版本和有效期检查的正文；相同条目只读一次。learned Skill 批量核对同一份状态与支撑记忆，再回读一次状态排除修订或撤销。保留记忆批次最终版本与有效期围栏、独立资源的正文指纹、已展示正文变化时的 409，以及 Host 最终身份复核。Skill 与记忆现有写入协议不改。

验证：用真实 Markdown 存储核对多条记录下的实际根索引/Skill 状态读取次数、撤销与范围检查；实跑原 Web 资源权限回归。原慢会话只允许在 UAT 内、隔离于运行服务的进程里复测候选，输出聚合指标，不导出正文、不写业务数据、不替换正在运行的镜像。候选链路耗时与实际服务 HTTP 首包分别报告。
