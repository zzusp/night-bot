# 已排空活动任务的新目标授权

## 目标与现场

旧效果按可能有局部效果结清后永久禁止重放。任务经普通 Router 修订或恢复后可以处于 active + drained，但当前 new-action 仅收 paused，且普通暂停 HTTP 入口已退役。不能为恢复新目标而清账本、伪造来源或放宽工具 guard。

## 选择

1. 重放旧 close 或直接改 SQLite：无法建立新目标授权且破坏审计，排除。
2. 另加通用暂停 API：扩大控制面，仅为既有授权流程前置一步，排除。
3. 扩展既有私密操作者 new-action：接受无在线 owner、active + drained 的任务；校验精确版本、全部 committed closure、原生调用和原范围后，先用确定性命令持久暂停，再沿现有来源、修订、激活流程继续。采用。

## 契约

提案仍绑定调用时的要求/控制版本。新增暂停有独立确定性收据；相同提案重试复用该收据，修订后/激活前的预期控制版本按暂停结果核对。暂停及后续各中断点均保持旧调用 noReplay，未激活不得执行新效果。已激活请求的幂等返回不变。模型、非操作者、未排空、旧版本、错误 closure 或变化 scope 仍拒绝；不升级权限，不改变任务 session，不自动部署业务项目。

## 验证

复用真实 Host/Pi、SQLite、私密 HTTP/CLI 的 action E2E。先以 active + drained 用例复现旧入口拒绝，再验证新路径成功、暂停/来源/修订中断后的冷恢复、相同请求幂等、拒绝非法提案不改变控制态、旧调用保持唯一且禁止重放。运行对应效果授权/结清反例与源码/hash/import 守卫。实际安装恢复与业务 Excel 验收必须另取运行证据，不能以夹具替代。
