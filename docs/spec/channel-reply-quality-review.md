# 渠道回复发送前复核（历史）

本文记录最初设计，已由[渠道正文直达与任务提及](channel-reply-direct-delivery.md)取代。

UAT 真实收据反证了“未部署”与“未读到规范”：现行提示已到达，但没有约束模型提交的最终正文。只改提示不能覆盖这个缺口；固定词表会误挡引用、明确要求的报告和其他语言；让额外模型重写则可能越过原作者、事实与授权边界。采用原会话写作 + 同一已配置模型路由的无工具语境复核。程序强制核对每条候选的结构化决定，退回原会话重写，不代写或改写冻结内容。核心规范始终进入写作上下文，完整示例仍按需查阅。

范围是 UAT 所使用的新分诊首答与 Router 直接回复（含面向渠道的任务交付说明），以及渠道关联任务直接向需求提出者发出的新问答。平台固定或定时通知、操作者专用通知、任务详情页问答、历史/已冻结的发送、附件字节、任务内部记录、通过任意 CLI 外发的文字不经过这个新出口。无回覆的分诊不请求复核；最多一个复核请求覆盖当前分诊批量。复核只见本次候选、用途和必要的原消息文本，不给工具、历史、附件、配置或授权；格式识别出的凭据不进入复核。失败时保留未冻结状态，不静默发送原稿；来源/世代复核与既有安全检查仍执行。语义判断有模型误差，不声称数学意义上的自然度保证；验收分开报告强制接线与真实模型质量。
