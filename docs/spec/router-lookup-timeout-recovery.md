# Router 查询定位与超时续办

- Router 接纳的消息身份绑定原文、来源版本和事件。`progressOnly` 是 Host 接纳查询后写回的权限状态，随时从账本校验，不属于原输入；续办仍验证原 Pi 检查点、原事件集合和效果收据。沿现有轮询/启动恢复，不另起模型重试或重发机制。 旧版若在入批时已带 `progressOnly`，Host 用当前账本重建旧版视图进行精确比较。新输入仍用不含该标记的规范视图，不改写原会话记录。
- 自动定位优先使用同会话当前来源或已核实的原生引用。没有这类绑定时，只将问题中点名的候选和有同会话近期来源记录的候选交给模型消歧；泛主题相似、更新时间靠前或唯一候选本身都不构成定位依据。找不到原事项时请用户补任务名或链接。
- 不用关键词推断任务语义，不跨会话匹配复制正文，也不取消有同会话上下文的接续问法。明确任务 ID 仍走原同会话校验。没有数据库格式、渠道或配置迁移。
