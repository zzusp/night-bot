# Router 回复来源引用

现有 Host 对分诊短回复默认绑定原消息；Router 结果一旦选择受众或任务文件，默认改为普通消息，仅 `replyToSource:true` 时引用。用户反馈后续处理结果缺少原消息引用。单改提示词仍依赖模型记住参数；按消息正文猜引用会误选来源。采用 Host 在支持原生引用的渠道上，在未指定受众或受众包含原作者时，为新建的 Router 回复默认绑定经验证的 `sourceId` / `messageVersion` 对应消息和作者；模型不选择其他引用对象。

显式受众仍控制提及；不含原作者时不添加引用，避免隐式通知未选中的人。原生引用可能隐式通知原作者，不能承诺静默。原已冻结通知继续原样去重和交付，不改写历史；平台定时回复与不支持原生引用的渠道维持既有合同。明确 `replyToSource:true` 的原受众校验、同会话约束和 stale/revoked 检查不放宽；文件子消息不继承引用。使用真实 Host、脚本模型及假渠道验证文本、附件父子件、旧冻结重试、权限和发送终态，不实发、不部署。
