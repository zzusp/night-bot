# 渠道结单回复：原问题与原生引用

结单批次可能只有任务结果，没有原问题的新消息。复用 Host 已校验的原来源和当前结果绑定，在模型输入中按结果事件提供原问题；工具参数仍用原绑定。Router 对照原问题与完整内部证据写正文，只保留影响答案或下一步的内容；明确要求依据时给所问细节。发送层不按关键词删文字，也不加复核模型。

原回复已在冻结账本缺少原生引用字段：该结果标为 `task-update`，与普通进展共用独立 Markdown 分支。新冻结且已核实绑定原提问的文字结果复用直接答复的引用校验，不靠模型另选目的来保证引用。普通进展、附件、无效绑定、旧冻结、不确定投递沿用原合同。来源和回执的追溯字段不是渠道原生引用。

脚本模型分别验证原问题接线、完整内部结果及发送信封；正文取舍需用真实模型和合成材料读回验收，原生引用需在钉钉独立读回原消息目标。升级无需配置或数据迁移，不处理历史已发回复。
