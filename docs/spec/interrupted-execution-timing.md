# 中断轮执行时长

正常执行继续按 SQLite 的领取和正常排空计算。冷恢复写入的排空时间是恢复操作时间，不当作原轮结束。对既有冷恢复收据，按任务及租约划定领取到冷排空的窗口；只在原 Pi 会话确认该轮输入后，用窗口内最后一条已提交记录时间作为估算结束。无同轮输入或可信记录时保持未知。容器时间不参与计算。

在 Host 恢复时读取一次有缺口的任务会话，存入同一 SQLite 的独立、无派发时长收据，绑定任务、会话、租约和原记录 ID。回填不改任务状态、原日记、业务效果或通知。已有估算不重复读会话；Web 分页只读收据并标「约」。拒绝用后来的任务轮次、恢复后一条工作记录或未提交尾部填前轮。无需增加新数据库或迁移表。
