# UAT 记忆与 Skill 原位更新

## 背景

UAT 第 136 代与 `e941587a` 对应。现场原回复未对上精确工具回执；源码显示全局 Router 不挂载完成证据修订工具，learned Skill 与安装文件也走不同写入边界。不能用同名副本模拟升级。

## 决定

- 针对当前核实结果复用已有记忆审阅、修订和 Store 事务；按已接纳事件精确取证明，不恢复结单自动复盘，不扩大写权限。
- learned Skill 继续走原 key/revision。安装项用真实注册表确认身份及来源，沿已认证、受版本约束的文件更新路径原地写；以隔离基线确认实际缺口，再决定是否需补窄入口。不把普通任务、群员或自检变成安装管理者。
- 双方只在持久回执与独立读回一致时说已完成；证据已覆盖时不写。冷启加载、重放、失效版本、权限和受保护文件都要有反例。详见[验收目标](../acceptance/uat-memory-skill-updates/goal.md)。
