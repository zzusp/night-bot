# 钉钉私聊保留同账号真人消息

UAT 的私聊在线，钉钉历史可读；旧插件在实时监听、范围补拉和最终接纳三个位置只认绑定对端，丢掉登录账号侧的真人消息。私聊内部 ID 也包含发送人，直接放宽会把同一私聊拆成两个 Router，Bot 发出的消息可能绕过原范围的回声收据。

沿用群聊的消息级回执防回声和未决发送暂缓，不按账号或通用 DWS 标记一律丢弃消息；保留 exact 对端、登录账号和原生会话校验。私聊仍以原对端派生同一个内部会话，作者和引用保留真人实际身份。继续使用单一指定私聊的订阅和原范围补拉，不订阅所有私聊，不重置水位或重放已过覆盖范围。

只放宽发送人条件会拆分历史并引入自回复风险；扩大订阅既不能替代已认证会话校验，也可能读取无关私聊。复用原防回声路径并固定会话身份，可同时保护历史、收发和任务归属。厂商没有推送的同账号消息只能走现有历史轮询，不能承诺实时。
