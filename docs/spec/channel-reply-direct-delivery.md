# 渠道正文直达与任务提及

- 去掉 Router 和任务执行提交渠道新正文时的独立语义复核。不按词表猜正文用途，也不再让第二次推理阻塞冻结。文风和回复时机留在撰写提示；Host 保留显式收悉拒绝、凭据和内部细节检查、取消、来源版本、授权、冻结、防重及回读。
- 群聊普通答复面向选中的真实问题作者；绑定任务完成或附件的回执默认原生提及同会话可验证的任务负责人（默认是发起人），不从最新消息猜受众。明确的同会话受众仍可覆盖默认；只有引用作者也在受众中时才引用。不猜身份，不把 @ 文本拼进正文。单聊仍回给已绑定对端。
- 不改历史冻结正文、受众、摘要或发送状态，不迁移数据。用既有 Host/Pi 与假渠道验证直接下发、跨作者回执和来源/版本及幂等反例；厂商实测单列。
