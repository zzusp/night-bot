# 执行历史资源复核合并锁

任务详情和 Router 走同一历史接口。UAT 样本任务首读约 2.2 秒，其中约 1.7 秒在资源复核；同一页无新增的刷新约 0.67 秒，其中约 0.63 秒在资源复核。现有批量读取仍对同一 Bot 记忆范围分别获取事实、learned Skill 状态、支撑索引和最终事实复核的磁盘锁。

- 选择复用一次现有 scope 锁：在普通 Skill 目录扫描之后读取当前根索引及匹配事实，最后读取 learned Skill 状态并再次判断有效期。以同一锁内的根索引校验事实和 Skill 的支撑；Skill 状态用原子文件的最新读取，继续比对 marker 和正文指纹。内存中组装结果，不跨请求缓存正文或权限。
- 不延长轮询或增加权限缓存：前者不减少单次等待，后者会延迟撤回已显示正文。暂不引入浏览器虚拟列表：本轮没有浏览器慢帧证据，虚拟化会改变锚点、已展开过程和搜索定位合同。
- 验证同一 HTTP 请求仅获取一次 Bot 记忆锁；保留变化、撤销、路径、到期、坏状态隔离和已发正文证明失效的回归。对比同一隔离夹具实际 HTTP 空轮询，UAT 只保留改动前的现场基线。
