# 会话上下文与角色摘要

## 目标与边界

一级分诊与 Router 使用精简必载规则、现有账本索引/查询和 Pi 原生角色摘要。长期行为指令复用共享 MarkdownMemoryStore，独立分类并按认证来源适用范围必载；普通笔记保持索引加按需读取。任务/通知账本保持唯一当前事实来源，不新增进度或回复状态库。不改预算、业务权限、原输入身份、历史 journal，不触碰运行数据、真实渠道、部署或合并。

## 决策快照

- 基线：origin/main b3cdb95（2026-11-17 fetch，Git Schannel）。独立分支 worktree-conversation-context，根检出既有修改不参与。
- 指令存于现有共享记忆预留 topic standing-instructions，增加准确 scope 元数据；仅当前认证来源经受控维护入口写入，普通记忆/后台学习不能提升权限。个人、会话、Bot 级分别遵循现有身份/管理边界，不自动迁移旧笔记。
- 分诊加载适用指令、原消息、现有近期背景和相关回复；Router 另加载分页任务索引和普通记忆索引。动态账本投影不改变已接纳业务 packet 身份。
- 扩展 resident_task_query(detail=progress)，新增只读 resident_reply_query；读取现有任务/通知/严格 Pi 会话，不唤醒任务、不重放。
- 保留 Pi 压缩章节、切分/近期保留、取消、新鲜度、提交和冷恢复；统一前台、后台与原生自动压缩的角色重点。优先 Pi 公开接口，不使用私有认证/重试方法或自建模型调用。
- 三种备选：全部写安装 AGENTS.md 无法保留逐用户范围；普通偏好全部必载会扩大适用性且增加输入；采用现有存储中的独立指令类型与准确范围。

## 验证

隔离目录、脚本模型、假渠道，覆盖范围/增改删/冷恢复、混合作者、任务和通知新鲜度、全部压缩路径及取消/no-replay。运行相关 routing/runtime 与原生守卫；Windows 平台阻断单列。唯一检查点与证据入口见 ../acceptance/conversation-context/goal.md。
