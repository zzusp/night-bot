# 任务模型按次重试间隔

UAT 指定任务模型路由需要在单次请求失败后，依次等待 5、10、15、30、60 秒再试。Pi 1.5.0 只支持指数退避及上限，无法用现有的基准值和上限精确表达这组间隔。

给 `providers.<路由>.retry.delaysMs` 增加显式等待序列，列表长度等于重试次数。仅在 Pi 自己的模型轮次重试处消费该列表；未配置时保留指数退避。不调整底层 HTTP 重试、请求超时、压缩重试、任务恢复、原输入或工具效果回执。用版本锁定的最小依赖补丁复用 Pi 的分类、取消、历史和预算机制；近似指数曲线会漏掉指定时间点，增加 Host 重试循环则会引入第二个执行责任层。

验证实际任务会话经过 5 次重试后停止，回执和执行租约不重放；配置及镜像安装沿用冻结锁。安装升级和对指定实例的配置启用单独执行，不改全局默认。
