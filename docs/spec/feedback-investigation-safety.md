# 反馈调查边界修复

目标：处理 PR #174 两轮审查的 23 条发现；以 `a0d2e58` 为起点，仅修改反馈调查实现、相关测试和说明，不接触运行中安装、业务数据、真实模型或 Issue 提交。

## 决策

- 文件读取：单纯调整 realpath/lstat 顺序仍无法消除父目录替换。采用已打开文件句柄的真实路径核验，并核对文件身份；Linux 使用 `/proc/self/fd`，Windows 使用已有 koffi/libuv 与系统句柄 API，macOS 使用系统 F_GETPATH。短读累计到固定字节边界；不足则显式失败。其他平台失败关闭。
- 查询：重复实时扫描无法稳定分页；采用本次调查内的有界、脱敏查询快照。只保存受控元数据，累计条数/字符达到预算时明确标记不完整。源码先整体识别多行敏感内容，再搜索、分页和标行号；长行支持字符续读。日志先投影白名单字段，再匹配 query，堆栈保留完整路径核验归属。
- Pi：复用原生 SessionManager 与自动压缩，不增加模型循环。Pi 1.5.0 已在 prepareNextTurnWithContext 中主动检查压缩，原“仅 agent_end 后检查”审查结论不成立。摘要鉴权必须由 ModelRuntime 解析，不能将预解析 OAuth 凭据再次当作显式 API Key。
- 报告：区分完整回答、输出截断和摘要失败；预算耗尽保留有界证据兜底。正文中的每个引用必须附证据或明确说明缺口；最终 Issue 统一预算，预留用户描述，所有裁剪显式提示。

## 验证

使用隔离文件、真实官方 Pi 加本地脚本 provider，覆盖私有路径/凭据边界、短读与目录消失、活跃日志分页、长源码续读、小窗口与中途压缩、摘要失败、length 终态和最终预览大小。接入常规测试入口，执行 `pnpm test` 及关联 Web 服务测试。不外发模型请求，不合并、不部署、不触发 CI。结果集中记录在 `docs/acceptance/feedback-investigation-review/`。
