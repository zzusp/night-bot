# Router 换代记录与消息布局

2026-11-09，基于 PR #10（仍未合并）承接；新 PR 向 main，包含其依赖。

## 已验证原因与修复

使用真实 createHost、官方 Pi、SQLite Router ledger、落盘会话和本地 HTTP 模型协议运行实例。模型回应由隔离测试控制，不使用真实密钥或厂商网络。处理输入后 Router 从第 1 代切到第 2 代：旧代投影 33 个条目，新代仅有私有交接等上下文，原 Web 投影为 0 条。修复后显示 5 条获准公开业务记录。

当前代已完整提交且公开记录为空时，只读取同一 conversation 的最近 published rotation 的已提交旧代。校验会话所有者、conversation、generation，沿用完整提交与正文脱敏规则。不投影私有交接、系统或思考。UI 明确显示历史与当前代次；revision 不匹配仍 409。测试另外验证跨会话 rotation 不读取。当前未提交、不可读不伪装成历史成功。

这是最近已提交上下文回退，不是完整历史归档浏览器；更早代次选择、压缩前历史和真实厂商现场尚未验证。真实任务的实时/完成后 HTTP 全链路本轮未补齐；已有 task session 真实落盘 API 回归通过，不能据此宣称覆盖了此次所有场景。

## 用户信息与界面

- 对话共用组件：用户右、助手左，两方气泡等圆角，移除复制图标；Web 与外部、自定义渠道共用。渠道输入仍隐藏。
- 任务头删除重复标签，保留标题、当前状态、更新时间和执行会话状态；目标与创建时间原生可键盘展开。
- 自进化显式显示 Web 身份范围，不将渠道群组与外部安装 Skill 的缺失解释为全站 0。未新增跨范围读取，不宣称接通用户现场。
- 当前 taskView 已提供状态、结果、阻塞、时间线；工具投影提供真实调用与返回状态。后续执行概览应围绕这些证据设计。当前未新增推测进度百分比、推测当前动作或将底层事件包装成用户进度。
