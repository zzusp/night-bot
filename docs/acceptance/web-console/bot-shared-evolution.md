# Bot 公共记忆、Skills 与真实使用来源

2026-11-09，已整合最新 main fcb39ce（新增四份验收文档，无代码冲突）。承接 PR #11 的最新产品修正：一个 Bot 共用一套记忆与 Skills，渠道仅作来源。不把此前 Web 身份的小范围统计称为完整交付。

## 实际能力与实现

核对当前锁定 Pi 的 AgentSession、parseSkillBlock、resourceLoader、官方 toolResult，以及 Night 的原生 skill 工具和已接纳命令收据；没有假设 Pi 提供语义“采纳/执行成功”的事件。

- `memoryScope` 对全部已认证绑定返回同一个 bot 标识；物理位置为 `data/memory/v2/bot`。读写、literal search、候选、提示短索引、旧结果撤销、任务复盘、学习技能目录和 Web 都用它。旧 personal/group/project 选择器只是别名。会话历史、任务来源授权、只读预设、显式写入同意、凭据保护和原始文件围栏保持。
- 新记忆/候选由 Host 接纳消息或真实任务账本记录来源，保存渠道 ID、chat/chat-room、会话名称/ID、任务 ID/标题；更正保留最新来源和最多 32 个不同来源描述。缺失历史信息为未知，不从文本猜。读取返回原来源；按真实条目返回／搜索命中记录访问次数和最后访问来源，与写入来源分开。
- 盘点运行时真实 Bot 技能根：标准 `data/config/skills`、owned agents/harness 的 skills，以及配置中安装内的 skillDirs。递归列出 SKILL.md/根级 Markdown 技能文件，标记有效可用、禁用、同名覆盖、嵌套但未接入和无效格式。不是任意扫描所有磁盘；敏感数据根、链接、越界跳过并显示不完整。文件 hash/mtime 是当前文件事实，不冒充全历史。既有用户技能不复制到 Git，也不被学习覆盖。
- 原生 `skill` 成功结果须与 Pi 实际 toolResult 精确配对并提交后才记模型调用；同内容重复成功调用也分别计数，事件 ID 幂等。Pi 已认证 `/skill:name` 扩展经接纳收据提交才记用户引用。实际 read/read_window 对应的精确技能文件读取单列，不能替代调用/采纳。目录与资源准备不计调用。
- 统计 SQLite 在公共 memory 私有数据目录；只存资源、版本、哈希事件 ID、模式和时间，不存消息正文、技能正文、查询、调用原始参数或凭据。资源 ID 使用安装相对位置以便迁移；版本比较不把学习资源中的全库 revision 标记变化误认为步骤变化。正常冷启动保留计数。
- Shell/外部程序读取、语义采纳、具体脚本执行成功和采集前历史没有可完整归因的官方事件，不推断。已观察调用可包含后来移除的资源；列表是当前状态。异常采集标明不完整，不声称所有可能的中断窗口均无遗漏。

## 旧库升级

portable Host 持有安装锁后做一次 copy-only 升级；非 portable 旧写进程须先停。v1 原文件保留：相同 key/body 合并来源，异值同名保留为带标记候选，不覆盖；旧计数各导入一次。学习步骤冲突用确定新名保留，支持记忆与 review destinations 改指公共库；任务档案也从公共路径取真实复盘。复制收据和最终标记让中断可续做；报告文件可重建，后续忘记不因重启重新导入旧值。链接/无效数据失败关闭。完整离线备份已包含 memory，SQLite 在 Host 关闭后复制；并未运行用户生产迁移或删除原库。
