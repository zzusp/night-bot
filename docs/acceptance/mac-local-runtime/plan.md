# Mac 本机运行验证

## 目标与范围

在当前 macOS 主机验证提交 `1514bbdfa26429b12bb2a6646b671206a3407498` 的锁定依赖安装、可选 Web 构建、真实 CLI/HTTP 启动交互与停机，以及相关运行测试。记录实际平台能力与失败，不将 Linux/Windows 历史结果追认为 Mac 已通过。

## 执行方案

1. 原样执行根目录和独立 Web 包的 `pnpm install --frozen-lockfile`，保留原生构建和供应链策略；构建 Web。
2. 使用隔离目录及 loopback 脚本模型运行现有 CLI/wire、路由、运行时与 containment 检查。实际启动管理入口和可选 Web，验证认证与 HTTP 交互、持久化和正常关闭。
3. 所有运行数据放入 Git 忽略的 `data/`；证据放本目录。失败追根定位，不关闭应用沙箱、不自动切换权限模式。
4. 在 `matrix.csv` 和 `round-N.md` 记录命令、结果、证据及未验边界；只有全部约定目标通过才写 `report.md`。

## 授权边界

不读取或更改已有业务安装，不发送真实渠道消息，不使用真实模型凭据，不部署、合并、触发 CI、提交或推送。`full` 仅在已有明确标注该模式的隔离测试中作为独立能力验收，不抵扣默认模式失败。
