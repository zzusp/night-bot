# 自进化流程：本地验收第一轮

2026-11-22，Windows，Node `24.19.0`、pnpm `11.25.0`。基线 `04d99575c4bc33a32a8caba21518ec8b4f6da9c3`（树 `12ca5c3362bba9cd8afd2b172b0fa17921c8d02a`）。本轮使用默认 Host、独立安装目录、Pi 环回脚本模型；仅启用指定用例需要的自动维护，不连接在役 Bot、真实模型或渠道。不发消息、不部署，不改真实记忆或 Skill。

## 结果

- 改前：复盘、准入、渐进召回和 Router 学习 27 项通过；维护、历史加载撤销和遗忘 31 项通过；原有独立任务实际联合读取记忆和 Skill 用例通过。以上证据覆盖链路，不证明真实模型的识别质量。
- [独立任务用例](../../../test/pi-single-task.test.js)：最终跑完 11 个独立任务会话。装箱报价从记忆读到容量 7 后以新件数 23 得出 4 箱；档案核验从 Skill 正文读到排序规则，在新三份材料中选 E；库存登记只读当前材料，登记实数 23，不调用学习工具。提交结算和排空均以账本回读为准，读取以严格 Pi journal 的工具回执为准。消费者请求未提供规则、内部键或答案。
- 对同类事项继续验证：容量改为 9，档案证据排序也因新证据更新；记忆 ID 不变，两个记忆和一个 Skill 均更新原条目而不加别名，旧版、原来源和两次实际 creator 生成可查。新的消费者分别得到 25 件需 3 箱、档案选 K。两条后续重复结论不新增、不升版。脚本提供语义判断；由 Host/Pi 实际发布、加载并把正文传回脚本用于本次计算。
- [事件维护用例](../../../test/pi-memory-maintenance.test.js)：新规则真实保存触发同轮维护，无需等每周定时检查；确认过时经验从索引移除、失去最后有效支持的 Skill 从目录和旧加载授权撤销、仍有有效支持的 Skill 保留。已经在用的派生文件不物理删除。旧版维护记录只列经验，未记录随之撤销的 Skill；改后同一份回执分别列出两项，带原 Skill 摘要及已撤销经验 ID，任务复盘归档的失败回调可补写，不重放动作。
