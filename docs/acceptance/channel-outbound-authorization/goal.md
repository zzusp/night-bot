# 渠道外发授权与真实验收

## 目标与完成条件

新增、编辑钉钉渠道时支持操作者显式授权或撤销外发；默认关闭，目标变更不继承授权，保存后正常重启生效。用已授权的既有测试安装验证原待发通知送达、平台回读和冷恢复不重复发送。用户随后反馈的定时提醒也须沿原来源处理链核实，不以旧回复通过替代新提醒通过。
