# UAT 已有文件交付、入库与回复

目标：修复已有任务原件回发、自然语言入库和跨渠道查读，以及回复中多余范围说明和字面量重复；在目标 UAT 验证真实终态。

| 子目标 | 当前检查点 |
| --- | --- |
| 发送原件 | 真实 Host + 模拟渠道通过：绑定账号请求后，已报告原件只送原私聊的实际对端（原任务作者），可读回相同字节。其他作者、会话和重发仍受限。 |
| 迁入知识库 | 仅入库保留原件，第二模拟渠道读回同版本、同字节；明确清理时，Linux 受限执行在原会话删除指定旧件，旁文件未动。 |
| 公开回复 | 回执明确实例共享和原件仍保留；Router 不再要求额外核实逐条可见性。钉钉客户端枚举、字段和路径尚待实显复验。 |
| UAT | 目标为 `db-dev/xxp-bot`。正式更新与真实业务验收分别取证；原私聊需获准的两侧测试入口，另一正式渠道需正常认证。仅合成数据，不代发、不动历史原件。 |

本轮基线 `ec130885f`，工作分支 `worktree-file-recipient-cleanup`。详见[方案](../../spec/channel-file-material-delivery.md)、[前轮验收](round-2.md)、[本轮验收](round-3.md)和[用例矩阵](matrix.csv)。
