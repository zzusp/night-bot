## 目标

## 范围与决策

- 独立 worktree-router-progress-followup，主检出已有修改不动；从 0a2aa75 开始，依次整合主线至 fe97ee6。各检查绑定的实际源码和哈希见 [round-1.md](round-1.md)。
- 不改分诊：本例分诊正确。不全面禁止 not-assigned：保留真正交给他人的事项。修正 Router 语义规则并验证实际模型工具选择。
- 复用 resident_task_query、resident_source_query/get、resident_router_reply 和原执行会话；不新增任务、审批、调度或字符串分类机制。
- 模型验证只复用当前安装选定的 Router 模型连接及凭据引用，密钥仅在内存中使用；不复制配置、凭据、记忆或真实业务数据，不连接真实消息渠道。
