## 关键排障与边界

- 新私有登录包装器先做语法检查；发现并修正正则转义后才发起设备流。包装器仅显示设备授权入口，退出时保留脱敏诊断，不打印或复制token。
- 云端配置中存在1个禁用DWS实例，最初“无DWS行”的预期不成立。只读核对它与config.example.json的初始化示例完全一致后予以保留，没有覆盖未知渠道或改本地配置。
- 厂商将测试通知的Markdown换行折叠为空格，故请求与读回不满足逐字节相等。保留这项展示差异：请求与厂商正文按空白规范化后等价，厂商正文与云端入站正文逐字一致，真实messageId一致；没有为此重复发送、去掉AI标记或改生产策略。
- 渠道提示词只是当前认证会话的职责输入，不创造集群RBAC、数据库/OSS凭据或跨项目授权。本轮没有新增API token挂载、集群权限、数据库/OSS接入或其他群。
- 新渠道起点由Host在官方新增事务中初始化，没有回拨ingressEpoch、注入消息、伪造Host档案或重放历史群消息。所有真实厂商操作均使用容器内DWS CLI。
- 第3/4轮未被本轮覆盖的基础运行、模型/GitHub结果和未验边界继续保留；不重复无关测试。DWS登录态跨Pod重建本轮未另测。
