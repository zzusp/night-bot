## 完成条件

- 人工答复后原 task/session 续办，答复接纳、执行及业务终态均有真实 Host/Pi 回归证据。
- 原生作业完成/取消后的终态与输出可靠可查；未知效果和原调用防重放不放宽。
- 分诊不提前承诺尚未确认授权的合并/发布；新要求覆盖失效要求，范围外并发变化不无故阻断当前交付。
- 性能改动有当前链路证据和有效回归；不宣称未经测量的真实模型/渠道速度收益。
- 完成受影响专项、适用路由/运行时组及源码守卫，保留失败、跳过与边界；提交 PR 并独立回查状态。

- 不自动合并、部署、发送真实消息或触发 CI；测试使用隔离安装、本地脚本模型及假渠道。
- 不复制凭据、真实业务数据或私有技能；不新增并行执行会话、自然语言字符串分类器或无限重试。
- 保留当前主体/会话/权限/来源版本、取消排空、严格日志和副作用防重放合同。
