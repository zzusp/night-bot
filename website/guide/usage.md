# 日常使用

以下操作发生在你自己的 Web 控制台中，不是本静态网站。先完成[安装与启动](./getting-started)，再验证实际模型可用。

## 发起任务与补充信息

在「与 Bot 对话」输入目标、材料和限制。Enter 发送，Shift + Enter 换行；中文输入法确认候选不会发送。

可从小而明确的任务开始：

- “把这份材料整理成要点，标出你无法核实的内容。”
- “先给我文件整理方案，未经我确认不要移动或删除文件。”
- “记住这个项目的术语；如果后续信息冲突，先向我核对。”

Web 使用一个固定对话，外部渠道的会话各自独立。任务执行期间可以补充要求；一个事项使用一个执行会话，不需要自行创建多组执行者。

**“已接纳”只表示消息已收到。** 任务状态和实际回复仍会继续更新。发送中断时保留草稿，先用「核对发送状态」检查原请求，不重复提交。关闭页面不会取消已接纳的工作；未发送草稿只在当前标签页内存中，刷新或关闭可能丢失。

## 看清任务进度

「任务」可按执行中、排队中、等待中和已结束筛选。等待可能来自缺少输入、依赖或审批，先查看实际原因。

在对话的「执行过程」中查看 Router 安排及关联任务；展开任务组读取正式执行上下文。任务详情也有执行记录。记录页显示当前可读取的历史范围，不能把页面投影当作完整原始审计。

任务完成不会自动授权后续动作。执行成功、结果发送和收件方实际收到也要分别核对；未知效果应保留现场，不能用重发来试探。

## 处理权限审批

认证安装操作者可在「权限与审批」查看 Host 报告的模式、保护状态和待审批动作。

- 核对动作、目标、工作目录和范围，再决定是否批准此次。
- 批准只绑定原调用与参数，不成为对其他动作的长期授权。
- “已批准”不是“已执行成功”；实际结果仍查看任务记录。
- 撤销只适用于尚未消费且仍有效的授权，不回滚已经发生的效果。

当前新安装默认 `full`，不提供工作区或进程隔离。已有显式 `ask` / `auto` 不改变；受限后端不可用时拒绝执行。详见[权限与安全](./security)。

## 记忆、技能与定时工作

Bot 共享长期记忆，并保留来源和读取权限。你可以要求记住、纠正或忘记信息；模型推断不应当作已确认事实或授权。

Router 可维护受管的学习技能，任务结束后也可另行复盘。学习不改写用户安装的正式技能，不扩大执行权限。Web「自进化」用于查看相关记录；正文读取仍有独立权限限制。

定时工作支持单次、固定间隔、每日、每周和五字段 cron。描述时说清执行内容、时区、时间和允许的动作，并核对实际保存的排期。停机恢复会处理到期事项，周期事项合并漏过轮次，而不是逐次补跑。

## 常见问题

**服务健康，但没有模型回复**：健康接口不验证模型。检查路由、模型 ID 和对应凭据状态，不要重发已接纳的请求。

**Web 提示资源未构建**：在相同代码版本的 `packages/web-console` 安装依赖并构建，不必把它解释成核心未启动。

**页面断线或会话过期**：先恢复连接或重新登录，再只读核对状态。网络故障不表示原操作没有执行。
